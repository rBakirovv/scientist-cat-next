# Отправка сообщения

Model/use-message-composer.ts хранит текст и ошибку, проверяет возможность отправки и обрабатывает Submit, Enter и Shift+Enter; серверная мутация берётся из публичного API entities/message.

Логика находится в хуках, UI-компоненты получают готовые данные и обработчики.
Разделение сохраняет существующие запросы, взаимодействия и публичные пропсы.

## Публичный API

Экспорт через `index.ts`: `MessageComposer`.
Внутренние хуки за пределы слайса не экспортируются.
