# Создание беседы

Model/use-user-picker.ts управляет выбором пользователя и переходом в чат; api/client/use-user-picker-data.ts загружает пользователей, выполняет prefetch и подключает мутацию создания.

Логика находится в хуках, UI-компоненты получают готовые данные и обработчики.
Разделение сохраняет существующие запросы, взаимодействия и публичные пропсы.

## Публичный API

Экспорт через `index.ts`: `UserPicker`.
Внутренние хуки за пределы слайса не экспортируются.
