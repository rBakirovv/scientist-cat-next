# Список бесед

Api/client/use-conversation-list.ts загружает список с резервным опросом; model/use-conversation-item.ts готовит состояние строки, дату и обработчик предварительной загрузки сообщений.

Логика находится в хуках, UI-компоненты получают готовые данные и обработчики.
Разделение сохраняет существующие запросы, взаимодействия и публичные пропсы.

## Публичный API

Экспорт через `index.ts`: `ConversationList`, `ConversationListSkeleton`.
Внутренние хуки за пределы слайса не экспортируются.
